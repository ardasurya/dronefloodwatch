# FloodWatch Drone

**FloodWatch Drone** is an AI-powered UAV and computer vision application developed for **MIIX 2026 Malaysia**. This project focuses on detecting waste accumulation in rivers using a YOLO-based object detection model from Roboflow and analyzing its potential contribution to flood risk.

The application is built using **Python** and **Streamlit**, making it easy to use through a web-based interface. Users can upload images, upload videos, or connect a realtime camera/drone stream to detect river waste and generate simple flood risk insights.

## Project Background

Sidoarjo, Indonesia, is a delta region with many rivers, drainage channels, and low-lying areas. These geographical conditions make the region vulnerable to flooding, especially during heavy rainfall and high-water flow conditions. One of the major contributing factors to local flooding is waste accumulation in rivers and drainage systems, which can block water flow and reduce river capacity.

FloodWatch Drone aims to provide a practical solution for river monitoring by combining drone-based image acquisition, artificial intelligence, and early flood risk analysis.

## Main Features

- River waste detection using YOLO and Roboflow
- Image upload detection
- Video upload detection
- Realtime camera or drone stream detection
- Bounding box visualization
- Simple flood risk score analysis
- Detection result table
- CSV export for reporting
- Streamlit-based web interface

## Model

This project uses a Roboflow Universe model:

**Model ID:** `trash-in-river/2`

The model is used to detect trash or waste objects in river environments.

## Expected Impact

FloodWatch Drone is expected to support cleaner rivers, faster environmental monitoring, and better flood prevention decision-making. By identifying river sections with high waste accumulation, stakeholders can prioritize cleaning actions before the waste causes serious water flow obstruction and flood risk.

## Disclaimer

This application is a prototype for innovation, education, and research purposes. The flood risk score generated by the system is an early analytical indicator and should be validated with field inspection, hydrological data, rainfall intensity, river flow, and official disaster risk assessment.
